# Screenshots

This folder is for **genuine screenshots of the running application**. None are included in the starter project - capture them yourself after you have run the app, and never fake or mock them.

## How to capture

1. Start both terminals (see the main `README.md`): server on port 5000, client on port 5173. Open `http://localhost:5173`.
2. Windows: press `Win + Shift + S`, drag over the browser window, then paste into Paint and save as PNG. (macOS: `Cmd + Shift + 4`.) Use a browser window of about 1280 px width so layouts are readable.
3. Save each file in this folder with exactly these names:

| File name | What to show |
|---|---|
| `01-home.png` | Home page with statistics, category cards and recent reports |
| `02-report-form.png` | Report Issue form (ideally with the similar-report warning visible) |
| `03-track-complaint.png` | Track Complaint page showing a result with status history |
| `04-public-issues.png` | Public issue list with search and filters |
| `05-admin-dashboard.png` | Admin dashboard with statistics and the complaint list |
| `06-admin-update.png` (optional) | Admin detail panel while updating a status |

4. Check each image: no real e-mail addresses, passwords or personal data visible.
5. Commit the PNG files, and add them to the "Screenshots" section of the main README, for example:
   `![Home page](screenshots/01-home.png)`

Do not claim a screenshot exists until you have captured it from your own running copy.
